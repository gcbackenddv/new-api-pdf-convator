# File Conversion API

## Run locally

From the project root, start the development server:

```powershell
.\venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

Open `http://127.0.0.1:8000/` to use the HTML, CSS, and JavaScript API tester. Upload sample files in the conversion forms to send requests and download the results.

Interactive API documentation is available at `http://127.0.0.1:8000/docs`.
